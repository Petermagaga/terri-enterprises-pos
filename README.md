
# Terri Enterprises POS

A cloud-based Point of Sale and Inventory Management System for Terri Enterprises.

## Technology Stack

- Backend: Python, Django, Django REST Framework
- Frontend: React
- Styling: Tailwind CSS
- Database: PostgreSQL
- Version Control: Git and GitHub

## Core Features

- Point of Sale and checkout
- Retail and wholesale pricing
- Product and inventory management
- Supplier and purchase management
- Stock batch tracking and FIFO costing
- Cash and M-Pesa payment recording
- Low-stock alerts
- Sales and profitability reporting
- Owner dashboard

## Project Structure

- `backend/` - Django backend
- `frontend/` - React frontend
- `docs/` - Project documentation
